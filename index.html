Hermes personal

A private, self-hosted mail connector for its account owner. This application is not offered to the public.

What the connector does

It connects the owner's personal assistant to the owner's mail accounts. Google access uses the Gmail API with the gmail.readonly permission. The current release checks connection status and the identity of the connected account. It does not retrieve message content.

The current assistant interface exposes only connection status and connection checks. Reading or searching messages requires a separate implementation and updated disclosures before it is enabled.

Data handling

OAuth credentials are kept in a separate restricted service on the owner's server. The assistant does not receive raw credentials. The current connector does not change email flags, send email, or delete email.

This public information site contains no mailbox data, assistant history, configuration files, or credentials.
